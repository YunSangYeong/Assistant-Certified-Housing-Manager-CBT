# Assistant-Certified-Housing-Manager-CBT

주택관리사보 **1차 통합 학습용 CBT**. React·TypeScript·Vite 정적 앱이며 서버·로그인·유료 API가 필요하지 않습니다.

전기기능사 CBT의 화면·학습 기능을 MIT 조건으로 재사용했습니다. 정책은 `YunSangYeong/electrician-cbt` 최신 main `76b990b8720adfa85c22a0a8f699b17094aa357b`의 CBT 표준 **v1.4.0**, 앱 소스는 고정 커밋 `b9a682ccff1b460334b78d5bfad9375b7ec4fbb6`입니다. 스킬 폴더 전체를 `.agents/skills/cbt-site-standard/`에 복사했고, 기존 AGENTS.md가 없어 연결 문서를 신규 작성했습니다. 원본 프로젝트는 수정·배포하지 않았습니다.

## 실행

Node.js 22.12 이상, 권장 24 (`.node-version`: 24.19.0). 이 환경에서는 24.22.1, npm 11.9.0으로 검증했습니다.

```sh
npm ci --cache /tmp/housing-npm-cache --no-audit --no-fund
npm run dev
npm test
npm run build
npx playwright install --with-deps chromium
npm run test:e2e
```

이미 설치된 시스템 Chromium을 사용할 때:

```sh
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:e2e
```

현재 체크아웃에서 작업합니다. 별도 worktree는 요청받지 않으면 만들지 않습니다. 정적 산출물은 `dist/`, Pages base는 `/Assistant-Certified-Housing-Manager-CBT/`입니다.

## 기능

- 실전 모의시험·랜덤 문제풀이, 두 모드 답안 선택 후 Space 이동, 입력·버튼·대화상자 및 마지막 문제 보호
- 과목별 40문항 추출, 평균 점수와 과목별 과락 판정, 기한 기반 자동 제출·새로고침 복원, 시험 중 정답 비공개
- 정답·전체 해설, 오답 복습·북마크·학습 통계, JSON 기록 백업·확인 후 초기화
- JSON/CSV 로컬 등록·원자적 검증·ID 및 정규화 본문/보기 중복 제거·검수 대기·근거를 입력한 로컬 승인·검색·페이지·내보내기
- 한국어 PC/모바일 화면, 짧은 세로/가로 화면의 독립 스크롤 메뉴, 학습 기준/연도 선택 메뉴 없음
- 상시 면책 배너 없음. 비공식 표시는 사이드바/푸터, 규칙·자료 한계는 문제은행 관리에서 안내. 실제 저장 오류는 경고 유지

## 시험 규칙과 공식 확인 상태

**최신 공식 원문 대조 미완료. 공식 시험 재현 완료가 아닙니다.** 설정은 `src/qualification.json`에 분리했습니다.

| 항목 | 현재 학습용 설정 |
| --- | --- |
| 범위 | 1차 회계원리·공동주택시설개론·민법 |
| 문항·보기 | 과목별 40문항, 총 120문항, 5지선다 |
| 배점 | 각 과목 100점, 정답당 2.5점, 미응답 오답 |
| 판정 | 평균 60점 이상 AND 모든 과목 40점 이상; 표시 반올림 이전 비율로 판정 |
| 시간 | 150분 통합 연습 타이머 |

일반적으로 알려진 1차의 1교시 100분(회계·시설), 2교시 50분(민법)을 **통합**했습니다. 실제 교시 전환·교시별 답안 잠금·휴식은 구현하지 않았습니다. 2차 주택관리관계법규·공동주택관리실무의 주관식 및 선발예정인원에 따른 합격자 결정은 구현하지 않았습니다. 이를 공식 전체 시험 모사로 사용하면 안 됩니다.

확인을 시도한 공식 자료(2026-11-08, KST 기준):

- [Q-Net 종목 정보](https://www.q-net.or.kr/crf005.do?id=crf00503&jmCd=9650)
- [국가법령정보센터 공동주택관리법 시행령](https://www.law.go.kr/법령/공동주택관리법시행령)

두 요청 모두 실행 환경 프록시에서 `curl: (56) CONNECT tunnel failed, response 403`, HTTP 연결 코드 `000`으로 차단됐습니다. 원문을 읽었다고 인용하지 않습니다. 공식 출제기준·최신 변경·기출의 이용 허락은 확인하지 못했습니다. Q-Net 기출/민간 문제를 복제하지 않았습니다.

## 실제 문제은행

중복 제거 후 `src/data/questions.json`에 **자체 제작 1,000개**를 등록했습니다. 내부 검토 기준 reviewed 1,000개, pending 0개, 제외 0개, 목표 대비 부족 **0개**. 외부 전문가 검수 완료 수는 **0개**입니다. 유형별 수를 독립 개념 수와 구분해야 합니다.

| 과목 | 개념 문항 | 계산 조건 조합 | 합계 |
| --- | ---: | ---: | ---: |
| 민법 | 40 | 0 | 40 |
| 회계원리 | 0 | 8유형 × 60조건 = 480 | 480 |
| 공동주택시설개론 | 0 | 8유형 × 60조건 = 480 | 480 |
| 합계 | 40 | 16유형 × 60조건 = 960 | **1,000** |

원문 기출 **0**, 복원 **0**, 자체 제작 **1,000**. 독립 개념/계산 유형은 총 **56**이고 숫자 조건 변형 960개를 960개의 독립 개념이나 기출로 보아서는 안 됩니다. 과목 간 은행 수와 개념 범위가 균등하지 않으며 공식 난이도·출제 범위 전체를 충족하지 않습니다. 시험에서는 등록 수와 별개로 각 과목 40개를 선택합니다. 계산 유형마다 최초 한 슬롯을 배정하고 나머지를 보충하므로 한 회 시험에서 같은 계산 유형이 반복될 수 있습니다.

모든 문항의 연도·회차는 null입니다. AI 일반 지식에 기반한 자체 작성이며, 저장소 URL은 작성 위치일 뿐 외부 정답 증빙이 아닙니다. 읽지 못한 법령/교재를 출처로 기재하지 않았습니다. 개념·선택지·해설은 내부 검토, 계산 960개는 별도 TypeScript 식으로 재계산·단위·정답 위치·동치 보기 검사를 수행했습니다. 외부 전문가 검수, 최신 판례·법령 검증, 공식 출제기준 대조와 구별합니다. 민법은 일반 개념 학습용이며 개별 사건의 예외나 최신 법정 수치를 다루지 않습니다.

## 저장 정책

localStorage 키 `housing-manager-cbt:v1`은 다른 자격증과 분리됩니다. 최근 응답 5,000개·시험 결과 30회를 보관하고, 오답·북마크·진행 시험·연습·개인 문항을 이 브라우저에 저장합니다. JSON 백업 내보내기를 제공하며 **백업 UI 복원 기능은 없습니다**. 손상된 기록은 자동 덮어쓰지 않습니다. 저장 차단/쿼터 오류는 경고하며, 초기화는 확인 후 사용자 기록과 로컬 문항만 지웁니다. 시크릿·iframe 저장 제한, 다른 origin의 기록 분리에 유의해야 합니다.
